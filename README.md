Copyright (c) 2026 Kyle. All rights reserved.

Android WebView app wrapping the Ravelin honey-pot security console.

## Build APK on GitHub

1. Open **Actions**
2. Run workflow **Build APK** (or push to `main`)
3. When it finishes, download **ravelin-debug-apk**
4. Install the `.apk` on your phone (allow unknown sources)

Package: `com.aegisscan.app`  
This is a debug APK for sideload, not a Play Store release.

## Local

Open this folder in Android Studio → Build APK.
